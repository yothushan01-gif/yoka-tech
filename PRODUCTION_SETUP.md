# Production setup checklist

1. Create a Firebase project.
2. Add Android app package id (choose your final package id, e.g. com.yokatech.shop).
3. Add Firebase Android configuration generated by FlutterFire.
4. Enable Firebase Authentication.
5. Enable Firestore.
6. Create role documents: owner, cashier, technician.
7. Add Firestore security rules so staff can only access permitted collections.
8. Add WhatsApp provider credentials separately (never commit secrets).
9. Configure invoice shop name, address, phone and tax fields.
10. Run `flutter pub get` and `flutter build apk --release`.
